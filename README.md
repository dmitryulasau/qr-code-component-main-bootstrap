## Bootstrap Refactoring - Reflection Questions

**1. What challenges did you face when refactoring your code to use Bootstrap?**

The most challenging part was adjusting my existing CSS to work with Bootstrap without breaking the original design.

**2. How did using Bootstrap utility classes and components simplify your styling process?**

Bootstrap made styling faster and easier because I didn't have to write custom CSS for everything. I could use utility classes for spacing, colors, alignment, and responsive layouts.

**3. In what scenarios might you choose not to use Bootstrap and write custom CSS instead?**

I would choose custom CSS when I need more control over the design or when creating something unique that Bootstrap doesn't support easily. Custom CSS is also useful when I want to avoid unnecessary framework styles.
